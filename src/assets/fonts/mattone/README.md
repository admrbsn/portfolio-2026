# Mattone

By Nunzio Mazzaferro, published by Collletttivo —
https://www.collletttivo.it/typefaces/mattone (source:
https://github.com/collletttivo/mattone). SIL Open Font License; see
LICENSE.txt. The `.woff2` is the foundry's own release file, unmodified.

Bold only: headings ask for 600 and the homepage hero for 700, and both
resolve to Bold. Regular and Black also exist.
